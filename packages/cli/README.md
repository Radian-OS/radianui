# 🌐 Radianos CLI

Welcome to **Radianos**, the CLI tool for rapid, streamlined Next.js project setup. Radianos makes it easy to kickstart your Next.js application with just one command, skipping the typical setup prompts and configuring your project with default settings and custom options.

---

## 📥 Installation & Quick Start

No installation is required! Run the CLI directly with the following command:

```bash
npx radianos@latest init
```
