## Usage

### Imports

```tsx showLineNumbers title=" "
import {
	Popover,
	PopoverContent,
	PopoverTrigger,
} from "@/components/ui/popover"
```

### Code

```tsx showLineNumbers title=" "
<Popover>
	<PopoverTrigger>Open Popover</PopoverTrigger>
	<PopoverContent>This is a simple popover content</PopoverContent>
</Popover>
```

### Emoji Reaction Picker

A reaction bar with search, categories, skin tones, recent selections, and a virtualized emoji list.

<ComponentPreview
	path="popover/popover-emoji-picker"
	title="Emoji Reaction Picker"
/>

Install [`unicode-emoji-json`](https://www.npmjs.com/package/unicode-emoji-json) ([documentation](https://github.com/muan/unicode-emoji-json#readme)) and [`@tanstack/react-virtual`](https://www.npmjs.com/package/@tanstack/react-virtual) ([documentation](https://tanstack.com/virtual/latest/docs/framework/react/react-virtual)) alongside the Popover, Input, Button, Scroll Area, and Sonner components. For flag font support in this example, manually install [`noto-color-emoji-flags`](https://www.npmjs.com/package/noto-color-emoji-flags) ([documentation](https://github.com/malekpour/noto-color-emoji-flags#readme)) and add `@import "noto-color-emoji-flags";` and the utility below to your global stylesheet.

<br />
The font and CSS work together: `noto-color-emoji-flags` supplies country and
subdivision flag glyphs that some platform fonts lack, especially on Windows,
where flags can appear as two-letter codes. Its CSS import registers the web
font; the `font-emoji` utility applies it to the picker and falls back to Apple,
Segoe UI, or Noto emoji fonts for smileys, people, and other characters.
Installing the package alone does not apply the font.
<br />
Keep the import before other CSS rules and use `font-emoji` on emoji elements,
as this example does. This improves rendering across platforms, although newer
emojis still depend on the browser and available system fonts. The flag subset
does not provide every emoji or make their artwork identical across devices.
This setup is added manually for the example; the CLI does not install the font
or add these styles.

<br />

```css
@import "noto-color-emoji-flags";

@utility font-emoji {
	font-family:
		"Noto Color Emoji Flags", "Apple Color Emoji", "Segoe UI Emoji",
		"Noto Color Emoji", sans-serif;
}
```

<br />
Copy these supporting files into `lib/emoji`:

## API Reference

### Popover

The root component. Alias for `Popover.Root` from Radix UI.

    ### PopoverTrigger

An interactive element that opens the popover when clicked.

    ### PopoverContent

The floating panel that appears when the popover is open.
