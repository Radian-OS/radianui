## Installation

The Date Picker is built using a composition of the [Popover](/docs/components/popover) and the [Calendar](/docs/components/calendar) components.

## Usage

### Imports

```tsx showLineNumbers title="/example/date-picker.tsx"
import { Calendar } from "@/components/ui/calendar"
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover
```

### Code

```tsx showLineNumbers title="/example/date-picker.tsx"
<Popover>
	<PopoverTrigger>Date</PopoverTrigger>
	<PopoverContent>
		<Calendar />
	</PopoverContent>
</Popover>
```
