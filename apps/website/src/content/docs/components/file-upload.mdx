### FileUploadDropzone

An interactive area that accepts dragged and dropped files from the user's operating system.

### FileUploadInput

A hidden input element that handles native file selection dialogues.

### FileUploadList

A structural container for displaying the list of currently uploaded or selected files.

### FileUploadItem

A wrapper for individual file entries, displaying file information and removal actions.
