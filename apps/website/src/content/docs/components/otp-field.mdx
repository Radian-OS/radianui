## Usage

### Imports

```tsx showLineNumbers title="/components/ui/otp-field.tsx"
import { OTPField, OTPHiddenInput, OTPInput } from "@/components/ui/otp-field"
```

### Code

```tsx showLineNumbers title="/components/ui/otp-field.tsx"
<OTPField>
	<OTPInput />
	<OTPInput />
	<OTPInput />
	{/* HiddenInput is required for the form to have data associated with the field */}
	<OTPHiddenInput />
</OTPField>
```

## API Reference

This component is built on top of [Radix UI OTP Field](https://www.radix-ui.com/primitives/docs/components/one-time-password-field). For advanced usage and additional props, please refer to their official documentation.

### OTPField

The root container. Alias for `OneTimeFieldPassword.Root` from Radix UI.

		},

    ### OTPInput

An individual input character cell within the OTP field.

    ### OTPHiddenInput

A hidden native input field used to capture the combined OTP value for form submission and accessibility.
