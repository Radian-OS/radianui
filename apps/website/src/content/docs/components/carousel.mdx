## Usage

### Imports

```tsx showLineNumbers title="/components/ui/carousel.tsx"
import {
	Carousel,
	CarouselContent,
	CarouselPrevious,
} from "@/components/ui/carousel"
```

### Code

```tsx showLineNumbers title="/components/ui/carousel.tsx"
<Carousel>
	<CarouselContent>
		<div>Slide 1</div>
		<div>Slide 2</div>
		<div>Slide 3</div>
	</CarouselContent>
	<CarouselPrevious>Previous</CarouselPrevious>
</Carousel>
```

## API Reference

This component is built on top of [embla-carousel-react](https://www.embla-carousel.com/).

### Carousel

Main wrapper for the carousel.

### CarouselContent

The flexbox container that holds all carousel items and handles the scrolling overflow.

### CarouselItem

A structural wrapper for individual slides or content blocks within the carousel.

### CarouselPrevious

An interactive button for navigating to the previous slide in the carousel.

### CarouselNext

An interactive button for navigating to the next slide in the carousel.
