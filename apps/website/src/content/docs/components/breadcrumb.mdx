## Usage

### Imports

```tsx showLineNumbers title="/components/ui/breadcrumb.tsx"
import {
	Breadcrumb,
	BreadcrumbEllipsis,
	BreadcrumbItem,
	BreadcrumbLink,
	BreadcrumbList,
	BreadcrumbPage,
	BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"
```

### Code

```tsx showLineNumbers title="/components/ui/breadcrumb.tsx"
<Breadcrumb>
	<BreadcrumbList>
		<BreadcrumbItem>
			<BreadcrumbLink asChild>
				<Link href="/">Home</Link>
			</BreadcrumbLink>
		</BreadcrumbItem>

		<BreadcrumbSeparator />

		<BreadcrumbItem>
			<BreadcrumbEllipsis />
		</BreadcrumbItem>

		<BreadcrumbSeparator />

		<BreadcrumbItem>
			<BreadcrumbLink asChild>
				<Link href="/docs/components">Components</Link>
			</BreadcrumbLink>
		</BreadcrumbItem>
	</BreadcrumbList>
</Breadcrumb>
```

## API Reference

This is a custom component made using Radix UI's Slot.

### Breadcrumb

The root navigation container that provides accessibility context (nav element) for the breadcrumb trail.

### BreadcrumbList

An ordered list container (`<ol>`) that groups and structures the breadcrumb navigation items.

### BreadcrumbItem

A wrapper (`<li>`) for individual breadcrumb links, separators, or current page indicators.

### BreadcrumbLink

An interactive link element used for navigating to previous pages in the breadcrumb trail.

### BreadcrumbPage

A static text element representing the current active page, automatically styled and configured for screen readers.

### BreadcrumbSeparator

A visual divider (typically a slash or chevron) placed between breadcrumb items.

### BreadcrumbEllipsis

A visual indicator used to represent hidden or truncated pages in a long breadcrumb trail.
