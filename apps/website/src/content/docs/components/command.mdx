## Usage

### Imports

```tsx showLineNumbers title="/components/ui/command.tsx"
import {
	Command,
	CommandDivider,
	CommandEmpty,
	CommandGroup,
	CommandInput,
	CommandItem,
	CommandList,
	CommandShortcut,
} from "@/components/ui/command"
```

### Code

```tsx showLineNumbers title="/components/ui/command.tsx"
<Command>
	<CommandInput placeholder="Type a command or search..." />
	<CommandList>
		<CommandEmpty>No results found.</CommandEmpty>
		<CommandGroup heading="Suggestions">
			<CommandItem>Calendar</CommandItem>
			<CommandItem>Search Emoji</CommandItem>
			<CommandItem>Calculator</CommandItem>
		</CommandGroup>
		<CommandDivider />
		<CommandGroup heading="Settings">
			<CommandItem>Profile</CommandItem>
			<CommandItem>Billing</CommandItem>
			<CommandItem>Settings</CommandItem>
		</CommandGroup>
	</CommandList>
</Command>
```

This component is built on top of [cmdk](https://cmdk.paco.me/).

### CommandDialog

A wrapper that renders the command menu inside a modal dialog.

    ### CommandInput

The text input field for filtering and searching through the command menu items.

    ### CommandList

A scrollable container that houses the command groups and items.

    ### CommandEmpty

A fallback container displayed when no command items match the current search query.

    ### CommandGroup

A structural container for grouping related command items under a specific heading.
