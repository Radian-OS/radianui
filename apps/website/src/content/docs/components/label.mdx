## Usage

### Imports

```tsx showLineNumbers title="components/ui/label.tsx"
import { Label } from "@/components/ui/label"
```

### Code

```tsx showLineNumbers title="components/ui/label.tsx"
<Label htmlFor="email">Your email here</Label>
```
