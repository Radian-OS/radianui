## Installation

<CLI mode="execute" code={`radianos add drawer`} />

## Imports

<Code
	language="tsx"
	code={`import 
  {DrawerWrapper,
  DrawerHeader,
  DrawerBody,
  DrawerFooter,
  DrawerClose} 
  from "@components/ui/Drawer"`}
/>

## Props

| Prop Name | Default Values | Values                       |
| --------- | -------------- | ---------------------------- |
| variant   | default        | float, default, rounded      |
| handle    | false          | true,false                   |
| position  | right          | top, bottom, left, right     |
| backdrop  | overlay        | backdrop, overlay, undefined |

## Usage

<Code
	language="tsx"
	code={`<Drawer
 trigger={<h1>Trigger</h1>}
 variant="default"
 handle={false} 
 position="right" 
 backdrop="overlay"
 >
<DrawerHeader>
   Drawer Header
   <DrawerClose><h1>Close</h1></DrawerClose>
</DrawerHeader>
  <DrawerBody>Drawer Body</DrawerBody>
  <DrawerFooter>Drawer Footer</DrawerFooter>
  </Drawer>
 `}
/>
