## Props

### Modal Props

| Prop Name     | Default Value | Possible Values                  |
| ------------- | ------------- | -------------------------------- |
| closeIcon     | "hidden"      | "visible", "hidden", "hover"     |
| backdrop      | "overlay"     | "overlay", "blur", "transparent" |
| withSeparator | false         | boolean                          |
| defaultOpen   | -             | boolean                          |
| open          | -             | boolean                          |
| onOpenChange  | -             | `(open:boolean):void`            |
| modal         | true          | boolean                          |
