## Usage

### Imports

```tsx showLineNumbers title="/components/ui/avatar.tsx"
import {
	Avatar,
	AvatarFallback,
	AvatarImage,
	AvatarIndicator,
	AvatarStatus,
} from "@/components/ui/avatar"
```

### Code

```tsx showLineNumbers title="/components/ui/avatar.tsx"
<Avatar size="48" rounded="circle">
	<AvatarImage src="https://radianos.com/logo.png" />
	<AvatarFallback>RS</AvatarFallback>
	<AvatarIndicator>
		<AvatarStatus variant="online" />
	</AvatarIndicator>
</Avatar>
```

## API Reference

### Avatar

The root container that groups all avatar sub-components and controls the shared size and shape.

<PropsTable

			defaultValue: "circle",
			required: false,
			description: "Sets the shape of the avatar",
		},
	]}
/>

    ### AvatarImage

The image element rendered inside the avatar. Hides automatically if the image fails to load.

    ### AvatarFallback

The fallback content displayed when the image is unavailable or still loading, typically initials or an icon.

    ### AvatarIndicator

A positioned wrapper that overlays the avatar, used to anchor the status badge at a corner of the avatar.

    ### AvatarStatus

A small colored badge indicating the user's current presence state such as online, offline, busy, or away.
