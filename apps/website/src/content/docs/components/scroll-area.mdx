## Usage

### Imports

```tsx showLineNumbers title="/components/ui/scroll-area"
import { ScrollArea, ScrollBar } from "@/components/ui/scroll-area"
```

### Code

```tsx showLineNumbers title="/components/ui/scroll-area"
<ScrollArea className="h-80 w-80 rounded-lg border p-2">
	<div></div>
</ScrollArea>
```
