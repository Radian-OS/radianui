## Installation

<Code language="bash" code={`npx radianos add toast`} />

## Imports

<Code language="tsx" code={`import {Toaster,showToast} from "@/components/ui/toast"`} />

## Props

| Prop Name     | Default Values | Values                                                                    |
| ------------- | -------------- | ------------------------------------------------------------------------- |
| position      | bottom-left    | top-left, top-center, top-right, bottom-left, bottom-center, bottom-right |
| state         | default        | default, information, success, error, warning                             |
| variant       | neutral        | neutral, strong, inverse                                                  |
| icon          |                |                                                                           |
| title         |                |                                                                           |
| description   |                |                                                                           |
| buttons       |                |                                                                           |
| placement     | horizontal     | horizontal,vertical                                                       |
| stackable     | boolean        | true/false                                                                |
| closable      | boolean        | true/false                                                                |
| visibleToasts | number         | 3, 4, 5                                                                   |

## Usage

	language="tsx"
