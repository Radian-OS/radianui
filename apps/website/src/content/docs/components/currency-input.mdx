## Usage

### Imports

```tsx showLineNumbers title="/components/ui/currency-input.tsx"
import { CurrencyInput } from "@/components/ui/currency-input"
```

```tsx showLineNumbers title="/components/ui/currency-input.tsx"
<CurrencyInput placeholder="Enter Currency Amount" />
```
