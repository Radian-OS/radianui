## Installation

The Combobox is built using a composition of the [Popover](/docs/components/popover) and the [Command](/docs/components/command) components.

## Usage

### Imports

```tsx showLineNumbers title="/components/ui/combobox.tsx"
import { Combobox } from "@/components/ui/combobox"
```

### Code

```tsx showLineNumbers title="/components/ui/combobox.tsx"
<Combobox>
	<Combobox.Input placeholder="Search..." />
	<Combobox.List>
		<Combobox.Item>Option 1</Combobox.Item>
		<Combobox.Item>Option 2</Combobox.Item>
		<Combobox.Item>Option 3</Combobox.Item>
	</Combobox.List>
</Combobox>
```
