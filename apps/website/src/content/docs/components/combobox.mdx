## Installation

The Combobox is built using a composition of the [Popover](/docs/components/popover), [Scroll Area](/docs/components/scroll-area) and the [Command](/docs/components/command) components.

---

## Usage

### Imports

```tsx showLineNumbers title="/example/comboboxPreview.tsx"
import {
	Command,
	CommandEmpty,
	CommandGroup,
	CommandInput,
	CommandItem,
	CommandList,
} from "@/components/ui/command"
import {
	Popover,
	PopoverContent,
	PopoverTrigger,
} from "@/components/ui/popover"
import { ScrollArea } from "@/components/ui/scroll-area"
```

### Code

```tsx showLineNumbers title="/example/comboboxPreview.tsx"
<Popover>
	<PopoverTrigger>Open Combobox</PopoverTrigger>
	<PopoverContent>
		<Command>
			<CommandInput />
			<CommandList>
				<CommandEmpty>No results found.</CommandEmpty>
				<ScrollArea>
					<CommandGroup heading="Suggestions">
						<CommandItem>Calendar</CommandItem>
						<CommandItem>Search Emoji</CommandItem>
						<CommandItem>Calculator</CommandItem>
					</CommandGroup>

					<CommandDivider />

					<CommandGroup heading="Settings">
						<CommandItem>Profile</CommandItem>
						<CommandItem>Billing</CommandItem>
						<CommandItem>Settings</CommandItem>
					</CommandGroup>
				</ScrollArea>
			</CommandList>
		</Command>
	</PopoverContent>
</Popover>
```

## API Reference

This component is a composite pattern built using [Popover](/docs/components/popover), [Command](/docs/components/command), and [ScrollArea](/docs/components/scroll-area). Refer to each component's individual API Reference for the full list of available props.

### Key Components Used

- **Popover** — Houses the dropdown overlay. See [Popover API](/docs/components/popover#api-reference).
- **Command** — Handles the search input and filtered list. See [Command API](/docs/components/command#api-reference).
- **ScrollArea** — Wraps long results lists for smooth scrolling. See [ScrollArea API](/docs/components/scroll-area#api-reference).
