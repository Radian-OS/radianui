## Usage

### Imports

```tsx showLineNumbers title="/components/ui/pagination"
import {
	Pagination,
	PaginationContent,
	PaginationEllipsis,
	PaginationItem,
} from "@/components/ui/pagination"
```

### Code

```tsx showLineNumbers title="/components/ui/pagination"
<Pagination>
	<PaginationContent>
		<PaginationItem>
			<Link href="#">First</Link>
		</PaginationItem>
		<PaginationItem>
			<PaginationEllipsis />
		</PaginationItem>
		<PaginationItem>
			<Link href="#">Second</Link>
		</PaginationItem>
	</PaginationContent>
</Pagination>
```

## API Reference

### Pagination

The root navigation container for the pagination component.

### PaginationContent

A structural container that groups and aligns all pagination items horizontally.

### PaginationItem

A wrapper for individual page links or navigation buttons within the pagination component.

### PaginationEllipsis

A visual indicator used to represent skipped pages in a long pagination sequence.
