## Installation

<Code language="bash" code={`npx radianos add pagination`} />

## Imports

<Code language="tsx" code={`import Pagination from "@/components/ui/pagination"`} />

## Props

| Prop Name          | Default Values | Values         |
| ------------------ | -------------- | -------------- |
| control            | icon           | icon,text,both |
| rowPerPage         | false          | true/false     |
| buttonVariant      | strong         | strong,outline |
| goToPage           | false          | true/false     |
| enableCustomRows   | false          | true/false     |
| totalPage          | -              | -              |
| currentPage        | -              | -              |
| onRowPerPageChange | -              | -              |
| onPageChange       | -              | -              |

## Usage

<Code
	language="tsx"
	code={`<Pagination 
currentPage="1" 
totalPage={50}
onPageChange={(page) => setCurrentPage(page)}
onRowsPerPageChange={(rows) => setRowsPerPage(rows)}
/>`}
/>
