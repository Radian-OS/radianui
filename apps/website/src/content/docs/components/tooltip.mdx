## Usage

### Imports

```tsx showLineNumbers title="/components/ui/tooltip.tsx"
import {
	Tooltip,
	TooltipContent,
	TooltipTrigger,
} from "@/components/ui/tooltip"
```

### Code

```tsx showLineNumbers title="/components/ui/tooltip.tsx"
<Tooltip>
	<TooltipTrigger>Hover Me</TooltipTrigger>
	<TooltipContent>This is a tooltip.</TooltipContent>
</Tooltip>
```

### Tooltip

The root container that manages the tooltip state and context.

    ### TooltipTrigger

An interactive element that opens the tooltip when hovered or focused.

    ### TooltipContent

The floating panel containing the tooltip text.
