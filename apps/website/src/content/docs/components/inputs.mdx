## Props

| Prop Name | Default Values | Values             |
| --------- | -------------- | ------------------ |
| rounded   | lg             | xs,sm,md,lg,xl,2xl |
| size      | 36             | 28,32,36,40,44,48  |
| label     | true           | true/false         |
| disabled  | false          | true/false         |
| lead      | icon           |                    |
| trail     | icon           |                    |
| hasError  | false          | true/false         |
| hint      |                |                    |

## Usage

<Code
	language="tsx"
	code={`<Input 
    rounded="sm"

    placeholder="Enter your username here"

/>`}
