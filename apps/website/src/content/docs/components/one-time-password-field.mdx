## Usage

### Imports

<CodeSnippet
	title="/components/ui/one-time-password-field.tsx"
	code={`import { OTPField, OTPInput, OTPHiddenInput } from "@/components/ui/one-time-password-field"`}

/>

### Code

<CodeSnippet
	title="/components/ui/one-time-password-field.tsx"
	code={`<OTPField>
		<OTPInput />
		<OTPInput />
		<OTPInput />
