## Usage

### Imports

```tsx showLineNumbers title="components/ui/menubar.tsx"
import {
	Menubar,
	MenubarCheckboxItem,
	MenubarContent,
	MenubarGroup,
	MenubarItem,
	MenubarLabel,
	MenubarMenu,
	MenubarRadioGroup,
	MenubarRadioItem,
	MenubarSeparator,
	MenubarShortcut,
	MenubarSub,
	MenubarSubContent,
	MenubarSubTrigger,
	MenubarTrigger,
} from "@/components/ui/menubar"
```

### Code

```tsx showLineNumbers title="components/ui/menubar.tsx"
<Menubar>
	<MenubarMenu>
		<MenubarTrigger>File</MenubarTrigger>
		<MenubarContent>
			<MenubarGroup>
				<MenubarItem>
					New Tab <MenubarShortcut>⌘T</MenubarShortcut>
				</MenubarItem>
				<MenubarItem>
					New Window <MenubarShortcut>⌘N</MenubarShortcut>
				</MenubarItem>
			</MenubarGroup>
			<MenubarSeparator />
			<MenubarGroup>
				<MenubarItem>
					Print... <MenubarShortcut>⌘P</MenubarShortcut>
				</MenubarItem>
			</MenubarGroup>
		</MenubarContent>
	</MenubarMenu>
</Menubar>
```

## API Reference

### Menubar

The root container. Alias for `Menubar.Root` from Radix UI.

    ### MenubarMenu

A top-level menu item within the menubar that contains a trigger and content.

    ### MenubarTrigger

An interactive element that opens its associated menu when clicked or hovered.

    ### MenubarContent
