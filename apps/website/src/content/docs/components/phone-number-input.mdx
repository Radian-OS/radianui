## Installation

The Phone Number Input is built using a composition of the [Combobox](/docs/components/combobox) and the [Input](/docs/components/input) components.
It utilizes the **usePhoneInput()** hook from **react-international-phone** library.

```bash
npm install react-international-phone
```
