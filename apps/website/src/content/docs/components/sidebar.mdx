A composable and accessible sidebar. Supports four themes, three variants, collapsible modes, a mobile drawer, and a keyboard shortcut out of the box.

> Keyboard shortcut: `Ctrl + B` toggles the sidebar from anywhere.

## Anatomy

`SidebarProvider` must wrap everything, it owns the state and exposes the useSidebar hook to all descendants.

<CodeSnippet title="app/sidebar.tsx" code={`
<SidebarProvider>              // State context, wraps entire layout
  <Sidebar>                    // The sidebar panel
    <SidebarHeader />          // Logo, workspace picker
    <SidebarContent>           // Scrollable middle section
      <SidebarGroup>
        <SidebarGroupLabel />  // Section heading
        <SidebarGroupAction /> // Section-level action (e.g. + button)
        <SidebarGroupContent>
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton />   // Nav link
              <SidebarMenuBadge />    // optional count
              <SidebarMenuAction />   // optional icon button
            </SidebarMenuItem>
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    </SidebarContent>
    <SidebarSeparator />       // Horizontal divider
    <SidebarFooter />          // User profile, help links
    <SidebarRail />            // Drag-to-resize rail
  </Sidebar>

  <SidebarInset>               // Main page content area
    <SidebarTrigger />         // Hamburger toggle button
    {/* page content */}
  </SidebarInset>
</SidebarProvider>
`}/>

## Basic Usage

<CodeSnippet title="app/sidebar.tsx" code={`
import { Home, Inbox, Settings } from "lucide-react"

const navItems = [
{ title: "Home", icon: Home, href: "/" },
{ title: "Inbox", icon: Inbox, href: "/inbox" },
{ title: "Settings", icon: Settings, href: "/settings" },
]

export default function AppLayout({ children }) {
  return (
    <SidebarProvider>
      <Sidebar>
        <SidebarHeader>
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton size="48">
                <Logo />
                <span>Acme Inc.</span>
              </SidebarMenuButton>
            </SidebarMenuItem>
          </SidebarMenu>
        </SidebarHeader>

        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupLabel>Platform</SidebarGroupLabel>
            <SidebarGroupContent>
              <SidebarMenu>
                {navItems.map((item) => (
                  <SidebarMenuItem key={item.title}>
                    <SidebarMenuButton asChild tooltip={item.title}>
                      <a href={item.href}>
                        <item.icon />
                        <span>{item.title}</span>
                      </a>
                    </SidebarMenuButton>
                  </SidebarMenuItem>
                ))}
              </SidebarMenu>
            </SidebarGroupContent>
          </SidebarGroup>
        </SidebarContent>

        <SidebarFooter>
          <UserMenu />
        </SidebarFooter>
      </Sidebar>

      <SidebarInset>
        <header>
          <SidebarTrigger />
        </header>
        {children}
      </SidebarInset>
    </SidebarProvider>

)
}
`}/>

## Themes

Pass theme to Sidebar>. The neutral-dark theme applies the CSS dark class internally, making it ideal for split light/dark layouts.

<CodeSnippet
	title="app/sidebar.tsx"
	code={`
<Sidebar theme="neutral-accent">   // Slightly tinted surface — default
<Sidebar theme="neutral-white">    // Pure white surface
<Sidebar theme="white-on-grey" variant="inset">  // White sidebar on grey page
<Sidebar theme="neutral-dark">     // Inverted dark sidebar
`}
/>

## Variants

Controls the visual shape and elevation of the sidebar container.

<CodeSnippet
	title="app/sidebar.tsx"
	code={`
<Sidebar variant="sidebar">   // Default — flush with page edge
<Sidebar variant="floating">  // Elevated: shadow + border + rounded corners

## Collapsible Modes

Controls what happens when the sidebar collapses. icon mode is popular for dashboards, navigation stays visible as a narrow icon strip.

<CodeSnippet
	title="app/sidebar.tsx"
	code={`
<Sidebar collapsible="offcanvas"> // Default — slides fully off-screen
<Sidebar collapsible="icon">      // Shrinks to icon-only strip
<Sidebar collapsible="none">      // Always visible, no toggle
`}
/>

In icon mode, SidebarMenuButton auto-resizes: height/width → 2rem, padding → 0.5rem, labels and badges are hidden via CSS. Add tooltip as a fallback label

## SidebarProvider

The root context component. Must wrap the entire layout, both the `Sidebar` and the `SidebarInset`. It manages open/closed state, persists it in a cookie (`sidebar_state`), registers the `Cmd+B` keyboard shortcut, and exposes everything via the `useSidebar` hook.

<br />
Uncontrolled — sidebar manages its own open/closed state internally. State is persisted in a cookie so it survives page reloads.
<br />
Controlled — you own the state. Useful when you need to open/close the sidebar in response to external events, like a route change or a keyboard shortcut you manage yourself.

| Prop           | Type                      | Description                     |
| -------------- | ------------------------- | ------------------------------- |
| `defaultOpen`  | `boolean`                 | Uncontrolled initial open state |
| `open`         | `boolean`                 | Controlled open state           |
| `onOpenChange` | `(open: boolean) => void` | Called when open state changes  |

## Sidebar

The sidebar panel itself. Renders as a fixed-position column on desktop and as a `Drawer` on mobile. Accepts `theme`, `variant`, `collapsible`, and `side` props to control its appearance and behavior.

| Prop          | Type                                                                     | Default          | Description             |
| ------------- | ------------------------------------------------------------------------ | ---------------- | ----------------------- |
| `theme`       | "neutral-accent" or "neutral-white" or "white-on-grey" or "neutral-dark" | "neutral-accent" | Color theme             |
| `side`        | `left` or `right`                                                        | `left`           | Which edge to anchor to |
| `variant`     | `sidebar` or `floating` or `inset`                                       | `sidebar`        | Visual shape            |
| `collapsible` | `offcanvas` or `icon` or `none`                                          | `offcanvas`      | Collapse behavior       |

## SidebarHeader

A div pinned to the top of the sidebar layout. It sits outside SidebarContent so it never scrolls — it's always visible. Typically holds your logo, app name, or a workspace/team switcher.

## SidebarContent

The scrollable body of the sidebar. Expands to fill all space between SidebarHeader and SidebarFooter via flex-1. Long nav lists scroll independently of the page content. In icon collapsible mode, overflow is hidden so content doesn't peek outside the narrow strip.

## SidebarCollapsibleTrigger

The clickable trigger that toggles a `SidebarCollapsible` open or closed. Typically placed inside a `SidebarGroupLabel` using asChild.

## SidebarCollapsibleContent

The animated content area that expands/collapses. Adds a group class so child components can react to the open/closed state.

## useSidebar

The useSidebar hook is used to control the sidebar.

| Property        | Type                          | Description                              |
| --------------- | ----------------------------- | ---------------------------------------- |
| `state`         | `"expanded"` or `"collapsed"` | Current visual state                     |
| `open`          | `boolean`                     | Whether sidebar is open on desktop       |
| `setOpen`       | `(open: boolean) => void`     | Open or close programmatically           |
| `openMobile`    | `boolean`                     | Whether the mobile Drawer is open        |
| `setOpenMobile` | `(open: boolean) => void`     | Open or close mobile Drawer              |
| `isMobile`      | `boolean`                     | True when viewport is below 768px        |
| `toggleSidebar` | `() => void`                  | Toggles desktop sidebar or mobile drawer |

<CodeSnippet
	title="app/sidebar.tsx"
	code={`
// Adapt content to sidebar width
function SidebarLogo() {
    const { state } = useSidebar()
    return state === "expanded" ? <FullLogo /> : <IconMark />
}
`}
/>

## Mobile Behavior

Below 768px, `Sidebar` renders as a Drawer automatically. The drawer direction matches the `side` prop.

<CodeSnippet title="app/sidebar.tsx" code={`
// Default trigger (PanelLeft icon)
<SidebarTrigger />

// Custom mobile trigger
function AppHeader() {
const { toggleSidebar, isMobile } = useSidebar()
return (

<header>
	{isMobile && (
		<button onClick={toggleSidebar} aria-label="Open menu">
			<MenuIcon />
		</button>
	)}
</header>
) }

// Override mobile drawer width

<SidebarProvider style={{ "--sidebar-width-mobile": "22rem" }}>
`}/>

> The mobile Drawer includes a visually hidden DialogTitle for screen reader support. Cookie-based persistence only applies on desktop, mobile Drawer state is session-only.
