## Data Table

We are using `TanStack Table` as the core logic layer and pair it with our `Table` component for the UI. This approach preserves flexibility while maintaining a consistent look and feel. The examples below showcase different ways to build data tables using `TanStack Table`. Some examples also integrate `dnd-kit` to enable draggable and re-orderable rows or columns.

## API Reference

This is a custom component, not a Radix UI wrapper.

### Table

The root structural container that manages the entire table layout.

### TableHeader

A structural container for the top section of the table, typically housing column headers.

### TableBody

The primary container for the main content rows of the table.

### TableFooter

A structural container for the bottom section of the table, often used for summaries or totals.

### TableRow

A structural wrapper representing a single horizontal row of data cells within the table.

### TableHead

A semantic cell representing a column or row header within the table.

### TableCell

A structural container representing an individual data cell within a table row.

### TableCaption

A text container providing a descriptive title or summary for the entire table.
