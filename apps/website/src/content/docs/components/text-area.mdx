## Installation

<Code language="bash" code={`pnpm radianos add textarea`} />

## Imports

<Code language="tsx" code={`import { TextArea } from "@/registry/ui/text-area"`} />

## Usage

<Code
	language="tsx"
	code={`<TextArea
label="Description"
resizable={false}
placeholder="Placeholder text..."
hasError={false}
disabled={false}
rows={4}
 />`}
/>
