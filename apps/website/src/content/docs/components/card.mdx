## Usage

### Imports

```tsx showLineNumbers title="/components/ui/card.tsx"
import {
	Card,
	CardAction,
	CardContent,
	CardDescription,
	CardFooter,
	CardHeader,
	CardTitle,
} from "@/components/ui/card"
```

### Code

```tsx showLineNumbers title="/components/ui/card.tsx"
<Card>
	<CardHeader>
		<CardTitle>Card Title</CardTitle>
		<CardDescription>Card Description</CardDescription>
		<CardAction>Card Action</CardAction>
	</CardHeader>
	<CardContent>
		<p>Card Content</p>
	</CardContent>
	<CardFooter>
		<p>Card Footer</p>
	</CardFooter>
</Card>
```

## API Reference

This is a custom component, not a Radix UI wrapper.

### CardHeader

A structural container for the top section of the card, usually housing the title and description.

### CardTitle

A semantic heading that establishes the primary subject of the card.

### CardDescription

A text container for providing supplementary context or details below the card title.

### CardContent

The main content area of the card, designed to hold the primary information or interactive elements.

### CardFooter

A structural container for the bottom section of the card, typically used for action buttons or links.

### CardAction

A wrapper for positioning interactive elements like buttons inside the card.
