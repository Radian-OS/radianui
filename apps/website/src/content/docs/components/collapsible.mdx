## Usage

### Imports

```tsx showLineNumbers title=" "
import {
	Collapsible,
	CollapsibleContent,
	CollapsibleTrigger,
} from "@/components/ui/collapsible"
```

### Code

```tsx showLineNumbers title=" "
<Collapsible>
	<CollapsibleTrigger>Can I use Radian UI in my project?</CollapsibleTrigger>
	<CollapsibleContent>
		Of course! Radian UI is a free and open-source design system and component
		library built with React and TypeScript. It provides a comprehensive set of
		accessible, customizable components for building beautiful user interfaces.
	</CollapsibleContent>
</Collapsible>
```

## API Reference

### Collapsible

Root component that manages the open/collapsed state and provides context to child components.

### CollapsibleTrigger

An interactive button element that toggles the collapsible panel open or closed. Styled wrapper for `Collapsible.CollapsibleTrigger`.

### CollapsibleContent

The panel that expands and collapses based on the root component's open state. Styled wrapper for `Collapsible.CollapsibleContent`.
