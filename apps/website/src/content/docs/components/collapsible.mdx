## Usage

### Imports

```tsx showLineNumbers title="/components/ui/collapsible.tsx"
import {
	Collapsible,
	CollapsibleContent,
	CollapsibleTrigger,
} from "@/components/ui/collapsible"
```

### Code

```tsx showLineNumbers title="/components/ui/collapsible.tsx"
<Collapsible>
	<CollapsibleTrigger>Can I use RadianOS in my project?</CollapsibleTrigger>
	<CollapsibleContent>
		Of course! RadianOS is a free and open-source design system and component
		library built with React and TypeScript. It provides a comprehensive set of
		accessible, customizable components for building beautiful user interfaces.
	</CollapsibleContent>
</Collapsible>
```
