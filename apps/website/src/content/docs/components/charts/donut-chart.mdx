## Usage

### Imports

```tsx showLineNumbers title=" "
import { Pie, PieChart } from "recharts"
import {
	type ChartConfig,
	ChartContainer,
	ChartLegend,
	ChartLegendContent,
	ChartTooltip,
	ChartTooltipContent,
} from "@/components/ui/chart"
```

### Code

```tsx showLineNumbers title=" "
<ChartContainer config={chartConfig}>
	<PieChart>
		<ChartTooltip content={<ChartTooltipContent />} />
		<ChartLegend content={<ChartLegendContent />} />
		<Pie
			data={chartData}
			dataKey="visitors"
			nameKey="browser"
			innerRadius={60}
		/>
	</PieChart>
</ChartContainer>
```

## API Reference

This is a custom component built on top of [Recharts](https://recharts.github.io/).

### ChartContainer

A structural wrapper that provides styling context and configuration for the chart via CSS variables.

### ChartTooltip

A wrapper for integrating custom, themed tooltips seamlessly into your chart.

### ChartTooltipContent

The internal content component for tooltips, responsible for displaying and formatting hovered data points.

### ChartLegend

A wrapper for embedding a custom, themed legend into your chart.

### ChartLegendContent

The internal content component for legends, mapping data keys to their respective colors and labels.

### ChartStyle

An optional component used to define or inject specific global styles and CSS variables required by the chart configuration.
