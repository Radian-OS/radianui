## Usage

### Imports

```tsx showLineNumbers title=" "
import {
	Banner,
	BannerContent,
	BannerDescription,
	BannerIcon,
	BannerTitle,
} from "@/components/ui/banner"
```

### Code

```tsx showLineNumbers title=" "
<Banner
	variant="strong"
	color="primary"
	onClose={() => setBannerVisible(false)}>
	<BannerContent>
		<BannerIcon>
			<Sparkles />
		</BannerIcon>

		<BannerTitle>New Feature!</BannerTitle>

		<BannerDescription>Check it out</BannerDescription>
	</BannerContent>
</Banner>
```

## API Reference

This is a custom component, not a Radix UI wrapper.

### Banner

The root container that groups all banner sub-components and controls the shared size and shape.

### BannerContent

The main container that groups the icon, title, and description text within the banner.

### BannerIcon

A wrapper for displaying visual indicators or SVG icons alongside the banner message.

### BannerTitle

A semantic heading that displays the main title or subject of the banner.

### BannerDescription

A text container for displaying the primary message or description of the banner.
