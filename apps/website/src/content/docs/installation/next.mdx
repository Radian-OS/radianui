## Create Project

Run the `init` command to create a new Next.js project or to setup an existing one:

<br />
<PackageManagerTabs
	commands={{
		npm: "npx radianui@latest init --next",
		yarn: "yarn dlx radianui@latest init --next",
		pnpm: "pnpm dlx radianui@latest init --next",
		bun: "bunx radianui@latest init --next",
	}}
/>

## Add Components

You can now start adding components to your project.

<br />
<PackageManagerTabs
	commands={{
		npm: "npx radianui@latest add button",
		yarn: "yarn dlx radianui@latest add button",
		pnpm: "pnpm dlx radianui@latest add button",
		bun: "bunx radianui@latest add button",
	}}
/>
<br />
The command above will add the `Button` component to your project. You can then import it like this:

<br/>
<CodeSnippet
					title="app.tsx"
					showLineNumber
					code={`
import { Button } from "@/components/ui/Button"

export default function App() {
  return (
    <div>
        <Button variant="strong"/>
            Button
        </Button>         
    </div>
  )
}`}
/>
