## Create New Project

Run the `init` command to create a new Next.js project:

```bash
npx radianui@latest init --next
```

### Configure components.json

You will be asked a few questions to configure `components.json`:

```bash title="Terminal"
√ No package.json found at C:\\Users\\RadianOS\\Projects. Create a new project? ... yes
√ What would you like to name your project? ... my-app
√ Would you like to use /src directory? ... yes
√ Which color would you like to use as your brand color? » Dark Orchid
√ Which font would you like to use for your project? » Inter - Inter Display (Default)
✔ Creating a new Next.js project. This might take some time.
✔ Writing components.json file
✔ Setting up project configuration
✔ Installing dependencies
✔ Updating global CSS variables

Success! Project initialization completed. You may now add components.
```

### Add Components

You can now start adding components to your project.

```bash
npx radianui@latest add button
```

<br />
The command above will add the `Button` component to your project. You can then
include it like this:

```tsx showLineNumbers title="app.tsx"
import { Button } from "@/components/ui/Button"

export default function App() {
	return (
		<div>
			<Button variant="strong">Button</Button>
		</div>
	)
}
```

## Existing Project

### Configure Tailwind CSS and Import Aliases

If you created your project with the default `create-next-app` settings, you can
skip this section.

<br />
If your project doesn't have Tailwind CSS installed, follow the official
[Next.js installation
guide](https://tailwindcss.com/docs/installation/framework-guides/nextjs) to set
it up first.

<br />
RadianUI components use the `@/*` import alias. Make sure your `tsconfig.json`
includes the following path configuration:

```json title="tsconfig.json"
{
	"compilerOptions": {
		"paths": {
			"@/*": ["./*"]
		}
	}
}
```

<br />
If your project uses the `src` directory, use `./src/*` instead:

```json title="tsconfig.json"
{
	"compilerOptions": {
		"paths": {
			"@/*": ["./src/*"]
		}
	}
}
```

### Run the CLI

```bash
npx radianui@latest init
```

<br />
The CLI will automatically detect your Next.js framework and Tailwind
configuration. You will be asked a few questions to configure your project, such
as brand color and font.
