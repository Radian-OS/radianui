## Create Project

Run the `init` command to create a new Vite project:

```bash
npx radianui@latest init --vite
```

## Configure components.json

You will be asked a few questions to configure `components.json`:

```bash title="components.json"

```

## Add Components

You can now start adding components to your project.

```bash
npx radianui@latest add button
```

<br />
The command above will add the `Button` component to your project. You can then
include it like this:

```tsx title="app.tsx" showLineNumbers
import {Button} from "@/components/ui/Button"

export default function App() {
  return (
    <div>
        <Button variant="strong" />
            Button
        </Button>
    </div>
  )
}
```

## In existing Project

### Install TailwindCSS

```bash
npm install tailwindcss @tailwindcss/vite
```

<br />
Replace everything in `src/index.css` with following

```css title="src/index.css" showLineNumbers
@import "tailwindcss";
```

### Edit tsconfig.json file

The current version of Vite splits TypeScript configuration into three files, two of which need to be edited. Add the baseUrl and paths properties to the compilerOptions section of
the tsconfig.json and tsconfig.app.json files:

```json title="tsconfig.json"
{
	"files": [],
	"references": [
		{
			"path": "./tsconfig.app.json"
		},
		{
			"path": "./tsconfig.node.json"
		}
	],
	"compilerOptions": {
		"baseUrl": ".",
		"paths": {
			"@/*": ["./src/*"]
		}
	}
}
```

### Edit tsconfig.app.json file

```json title="tsconfig.app.json"
{
	"compilerOptions": {
		// ...
		"baseUrl": ".",
		"paths": {
			"@/*": ["./src/*"]
		}
		// ...
	}
}
```

### Update vite.config.ts

Add the following code to the vite.config.ts so your app can resolve paths without error:

```bash
npm install -D @types/node
```

```ts showLineNumbers title="vite.config.ts"
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

export default defineConfig({
	plugins: [react(), tailwindcss()],
	resolve: {
		alias: {
			"@": path.resolve(\_\_dirname, "./src")
		}
	}
})
```
