## Create New Project

Run the `init` command to create a new Vite project:

```bash
npx radianui@latest init --vite
```

### Configure components.json

You will be asked a few questions to configure `components.json`:

```bash title="Terminal"
√ No package.json found at C:\\Users\\RadianOS\\Projects. Create a new project? ... yes
√ What would you like to name your project? ... vite-project
√ Which color would you like to use as your brand color? » Cyan
√ Which font would you like to use for your project? » Geist
✔ Creating a new Vite project. This might take some time.
✔ Writing components.json file
✔ Setting up project configuration
✔ Installing dependencies
✔ Updating global CSS variables

Success! Project initialization completed. You may now add components.
```

### Add Components

You can now start adding components to your project.

```bash
npx radianui@latest add button
```

<br />
The command above will add the `Button` component to your project. You can then
include it like this:

```tsx title="app.tsx" showLineNumbers
import { Button } from "@/components/ui/Button"

export default function App() {
	return (
		<div>
			<Button variant="strong">Button</Button>
		</div>
	)
}
```

## Existing Project

### Configure Tailwind CSS and Import Aliases

Install Tailwind CSS and the Vite plugin:

```bash
npm install tailwindcss @tailwindcss/vite
```

<br />
Replace everything in `src/index.css` with the following:

```css title="src/index.css" showLineNumbers
@import "tailwindcss";
```

<br />
The current version of Vite splits TypeScript configuration into three files,
two of which need to be edited. Add the `baseUrl` and `paths` properties to the
`compilerOptions` section of the `tsconfig.json` and `tsconfig.app.json` files:

```json title="tsconfig.json"
{
	"files": [],
	"references": [
		{
			"path": "./tsconfig.app.json"
		},
		{
			"path": "./tsconfig.node.json"
		}
	],
	"compilerOptions": {
		"baseUrl": ".",
		"paths": {
			"@/*": ["./src/*"]
		}
	}
}
```

```json title="tsconfig.app.json"
{
	"compilerOptions": {
		// ...
		"baseUrl": ".",
		"paths": {
			"@/*": ["./src/*"]
		}
		// ...
	}
}
```

<br />
Add the following code to `vite.config.ts` so your app can resolve paths without
error:

```bash
npm install -D @types/node
```

```ts showLineNumbers title="vite.config.ts"
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

export default defineConfig({
	plugins: [react(), tailwindcss()],
	resolve: {
		alias: {
			"@": path.resolve(\_\_dirname, "./src")
		}
	}
})
```

### Run the CLI

```bash
npx radianui@latest init
```

<br />
The CLI will automatically detect your Vite framework and Tailwind
configuration. You will be asked a few questions to configure your project, such
as brand color and font.
