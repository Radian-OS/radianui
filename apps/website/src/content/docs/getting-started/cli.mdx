## init

Use the **`init`** command to initialize configuration and dependencies for a new project.

<br />
The **`init`** command installs dependencies, adds the radianos util and CSS variables for the project.
<br />
<PackageManagerTabs
	commands={{
		npm: "npx radianui@latest init",
		yarn: "yarn dlx radianui@latest init",
		pnpm: "pnpm dlx radianui@latest init",
		bun: "bunx radianui@latest init",
	}}
/>
<br />
You will be asked a few questions to configure components.json:

<br/>

## add

Use the **`add`** command to add components and dependencies to your project.

<br />
<PackageManagerTabs
	commands={{
		npm: "npx radianui@latest add [component]",
		yarn: "yarn dlx radianui@latest add [component]",
		pnpm: "pnpm dlx radianui@latest add [component]",
		bun: "bunx radianui@latest add [component]",
	}}
/>
<br />
You will be presented with installation process:
<br/>
<CodeSnippet
	title="Terminal"
	code={`RadianOS v1.0.0

√ Checking registry
√ Installing the dependencies

Created 1 file(s):

- C:\\Project\\components\\ui\\accordion.tsx`}
  />
