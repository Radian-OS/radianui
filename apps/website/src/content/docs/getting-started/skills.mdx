Skills are files that provide full context of the project to your AI assistant. Radian UI provides specialized [skills](https://www.skills.sh/) to help you automate tasks and integrate with your AI agents. These skills offer comprehensive guides and references for the Radian UI components, design tokens, and theme system.

## Install

```bash
npx skills add Radian-OS/radianui
```

<br />
Use this command to install the Radian skill into your project. Once installed,
you can start building things with your AI assistant.

## Radian Skill

The core Radian skill serves as a comprehensive guide and reference for Radian UI. It gives your AI assistant detailed knowledge about:

- **CLI commands**: Proper guide of using the CLI tool commands.
- **Configuration**: Understanding and configuring the `components.json` file.
- **Components & Blocks**: Context on the Radian UI components and blocks.
- **Design System**: OKLCH design tokens and the theme system.
- **Styling Setup**: `utility.css` and `globals.css` configurations of your project.
