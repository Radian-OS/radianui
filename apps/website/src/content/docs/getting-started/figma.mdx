Available on the Figma Community, Radian is a free design system and UI kit built for solo designers, freelancers, startups, agencies, and organizations. With ever-expanding UI
layouts, components and patterns, Radian keeps evolving to support your growth and collaboration.

## Whats Inside?

<ol className="list-decimal list-outside pl-6 marker:font-bold marker:text-inherit marker:align-baseline font-heading text-fg-secondary">
	<li>
		<strong>Fundamentals:</strong> Built on a strict design system with ready-to-use colors, icons, spacing, and typography in Figma, ensuring consistency without rework.
	</li>
        <br/>
	<li>
		<strong>Components:</strong> All of core UI components like buttons, inputs, checkbox, and more. Each one created with different variants so you can customize according to your
		preference.
	</li>
        <br/>
    <li>
    	<strong>Auto Layout:</strong> Every component is built with the latest Auto Layout features ensuring all of the design are flexible, responsive and automatically adapt to your
    	design content.
    </li>
        <br/>

    <li>
    	<strong>Variable Modes:</strong> Switch themes effortlessly with variable modes, keeping your project clear and adaptable for all different modes.
    </li>
        <br/>

    <li>
    	<strong>UI Blocks:</strong> We've included multiple of ready-to-go website sections designs for various needs for you to get started quickly. You can use them as is or mix them
    	up to create something new.
    </li>

</ol>
