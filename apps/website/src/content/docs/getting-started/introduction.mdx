## Introduction

Radian is an open-source React component library and UI design system built to accelerate product development with beautiful defaults. Currently, available for **Next.js**, it's powered by **Tailwind CSS** and **Radix Primitives**, providing a solid foundation for modern web apps

<br />
Radian helps you design and iterate quickly, offering components that can serve as ready-to-use building blocks for your final product or as customizable starters for unique
projects. We've prioritized flexibility, ensuring common properties and behaviors are baked in—so you won't waste time rebuilding essentials.
<br />
Our goal? Deliver an exceptional out-of-the-box experience that makes designing, modifying, and shipping products faster and more enjoyable than ever.

## Advantages of Using Radian

**High Customizability**: Our components look great and are packed with features you can easily change to match your style. The design system is also very versatile in that sense.

<br />

**Open Code System**: All component code lives directly in your codebase, giving you full control to modify and extend without external dependencies after initialization.

<br />
**Rich Design System**: Radian offers one of the most comprehensive and easy-to-use, free design systems available, continuously improved with designer feedback.

<br />
**Best Out-of-the-Box Experience**: Zero setup required for polished results. Our defaults ensure your apps look professional and perform optimally right away.

<br />
**Growing Blocks Ecosystem**: We're actively developing reusable blocks based on common patterns and user flows, helping you assemble complex interfaces effortlessly.

<br />
**AI and beginner-friendly**: With all essential props included, Radian integrates smoothly with AI code generators. It's also ideal for newcomers, offering full code access for
experimentation and learning.

## Common FAQs

<Accordion>
	<AccordionItem value="item-1">
		<AccordionTrigger>What is Radian Built with?</AccordionTrigger>
		<AccordionContent>
			Radian leverages Radix Primitives for accessible foundations and Tailwind CSS for styling. We add targeted packages per component to enhance functionality without bloat.
		</AccordionContent>
	</AccordionItem>
	<AccordionItem value="item-2">
		<AccordionTrigger>Does Radian Support Tailwind?</AccordionTrigger>
		<AccordionContent>
			Absolutely Radian fully supports all Tailwind classes. For optimal theming, we recommend using Radian's CSS (e.g., for colors, typography, and headings) to maintain control
			and consistency.
		</AccordionContent>
	</AccordionItem>
	<AccordionItem value="item-3">
		<AccordionTrigger>Why use Open Code System?</AccordionTrigger>
		<AccordionContent>
			We encountered significant challenges when utilizing existing frontend development libraries. Customizing even basic elements, such as incorporating an icon within a
			checkbox, often proved to be a cumbersome and time-consuming process. This experience led us to conclude that a closed system for frontend code is not the best approach.
		</AccordionContent>
	</AccordionItem>
	<AccordionItem value="item-4">
		<AccordionTrigger>Is Radian a Copy-Paste Library?</AccordionTrigger>
		<AccordionContent>
			Yes, Radian employs an open code system. This enables users to copy and paste the code into their codebase directly, provided that the necessary dependencies are installed.
			Additionally, all code and files can be initialized through the command line interface.
		</AccordionContent>
	</AccordionItem>
	<AccordionItem value="item-5">
		<AccordionTrigger>Does Radian support TypeScript?</AccordionTrigger>
		<AccordionContent>Yes, Radian is fully TypeScript-native and type safe. JavaScript support isn't available yet, ensuring robust, error free development.</AccordionContent>
	</AccordionItem>
	<AccordionItem value="item-6">
		<AccordionTrigger>How do I update to the Latest Radian Component Changes?</AccordionTrigger>
		<AccordionContent>
			Currently, updates involve copying the latest code into your project. We're planning CLI commands to simplify this process in future releases.
		</AccordionContent>
	</AccordionItem>
</Accordion>
