## Radian Colors

Colors in Radian design system is built on minimal yet effective colors that is flexible enough to build an entire product on. The color system provides variables for all of the most common use cases while building an interface.

<br />
Colors are organized based on usage like text, border, background, & primary colors to ensure using color is easier for most people.

## Customizing your colors

1. **Explore Color Primitives:** Radian already offers 15+ base color ranges to choose from.

<Image src="/doc/colorprimitive.png" width="704" height="450" alt="Color Primitives" />
2. **Map Your Tokens(Design):** Create a smaller, more manageable set of design tokens that map to specific use cases.

<Image src="/doc/mapcolor.png" width="704" height="450" alt="Map Color" />
3. **Map Your Colors(Development):** Map the colors from your Figma file to Global CSS file. Convert to OKLCH color format for best performance on all devices.

<CodeSnippet
	title="css/global.css"
	lang="css"
	showLineNumber
	code={`@import "tailwindcss";

@theme {
--color-health: #121063;
--color-crypto: #3ab7b1;
--color-corporate: #78dcca;
} `}
/>
