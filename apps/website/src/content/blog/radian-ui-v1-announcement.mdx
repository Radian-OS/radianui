## What's New in v1.0

### 1. 50+ Accessible React Primitives

Every component is built on top of Radix UI primitives and styled with OKLCH CSS variables. From date pickers and drag-and-drop tables to command menus and phone inputs, you have every building block you need.

### 2. Pre-Built Application Blocks

Save hours of repetitive UI building with production-ready sections:

- Authentication screens (Login, Signup, 2FA)
- SaaS Billing & Pricing Tables
- Analytics Dashboards & Charts
- Marketing Hero & Feature Sections

### 3. Dedicated Figma UI Kit

The Radian Figma Kit mirrors the code 1:1. Variables, variants, typography scales, and auto-layout structures match the React component APIs directly.

### 4. Interactive CLI

Install components on-demand directly into your project repository with `npx radian add <component>`.
