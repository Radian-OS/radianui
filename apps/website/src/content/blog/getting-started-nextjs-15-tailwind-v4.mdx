## Prerequisites

Before starting, ensure you have Node.js 20+ and pnpm installed.

```bash
# Create a new Next.js 15 project
pnpm create next-app@latest my-radian-app --typescript --tailwind --eslint --app
```

## Initializing Radian UI

Run the Radian CLI inside your project root to configure paths and dependencies:

```bash
npx radian init
```

The CLI will detect your `tailwind.config` or CSS setup, install required Radix primitives and utilities (`clsx`, `tailwind-merge`), and create your `components.json`.

## Adding Your First Components

Unlike traditional component libraries distributed as monolithic npm packages, Radian UI is copy-paste first. You own the code:

```bash
npx radian add button input avatar dialog
```

The components will be placed directly in your `@/components/ui/` folder, ready for customization.

## Server Components vs Client Interactivity

Most Radian UI components are lightweight React Server Components by default. For interactive primitives like Dialog, Dropdown, and Tabs, Radian exports clean client wrappers that keep your bundle size minimal.
