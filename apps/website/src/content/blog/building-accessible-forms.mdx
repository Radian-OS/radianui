## Key Ingredients of Accessible Forms

An accessible form must satisfy several criteria:

- **Explicit Label Associations:** Form controls must be programmatically linked to `<label>` elements via `htmlFor` and `id`.
- **Clear Error Announcements:** Validation messages should leverage `aria-describedby` and `aria-invalid` to be read aloud by assistive technologies.
- **Predictable Keyboard Focus:** Tab order should be logical, and focus states should remain clearly visible.

## Integrating React Hook Form with Radian Input

Radian provides seamless integration with controlled form state:

```tsx
import { zodResolver } from "@hookform/resolvers/zod"
import { useForm } from "react-hook-form"
import { z } from "zod"
import { Button } from "@/registry/ui/button"
import { Input, InputWrapper } from "@/registry/ui/input"

const schema = z.object({
	email: z.string().email("Please enter a valid work email"),
})

export function NewsletterForm() {
	const {
		register,
		handleSubmit,
		formState: { errors },
	} = useForm({
		resolver: zodResolver(schema),
	})

	return (
		<form onSubmit={handleSubmit((data) => console.log(data))}>
			<InputWrapper>
				<Input placeholder="name@company.com" {...register("email")} />
			</InputWrapper>
			{errors.email && (
				<p className="text-error mt-1 text-xs">{errors.email.message}</p>
			)}
			<Button color="primary" type="submit">
				Subscribe
			</Button>
		</form>
	)
}
```

Radian's input wrappers handle focus rings, sizing, and error states automatically, giving you consistent styling across every device.
