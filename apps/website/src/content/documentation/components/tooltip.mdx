##### Installation

<Code language="bash" code={`npx radianos add tooltip`} />

##### Imports

<Code language="tsx" code={`import {Tooltip} from "@/components/ui/tooltip"`} />

##### Props

| Prop Name | Default Values | Values                   |
| --------- | -------------- | ------------------------ |
| position  | top            | top, left, right, bottom |
| variant   | default        | default, arrow           |
| content   | -              | -                        |

##### Usage

<Code
	language="tsx"

    variant="default">
