##### Installation

<Code language="bash" code={`npx radianos add alert`} />

##### Imports

<Code language="tsx" code={`import {Alert} from "@/components/ui/alert"`} />

##### Props

| Prop Name | Default Values | Values                                  |
| --------- | -------------- | --------------------------------------- |
| type      | default        | default, info, success, danger, warning |
| title     | -              | -                                       |
| message   | -              | -                                       |
| shaders   | false          | boolean                                 |

##### Usage

<Code
	language="tsx"
	code={`<Alert
