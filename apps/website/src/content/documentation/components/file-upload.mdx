## Installation

<Code language="bash" tabs={true} code={`radianos add file-upload`} />

## Imports

<Code language="tsx" code={`import FileUpload from "@/components/ui/file-upload"`} />

## Props

| Prop Name       | Default Values                        | Values             |
| --------------- | ------------------------------------- | ------------------ |
| variant         | input                                 | input/container    |
| accept          | image/\*                              |                    |
| rounded         | lg                                    | xs,sm,md,lg,xl,2xl |
| sizes           | lg                                    | xs,sm,md,lg,xl,2xl |
| maxSize (in mb) | 5                                     |                    |
| maxFiles        | 4                                     |                    |
| label           | true                                  | true/false         |
| disabled        | false                                 | true/false         |
| maxFiles        | 4                                     |                    |
| title           | Drag and drop files to upload         |                    |
| description     | JPG, PNG, GIF or other image files    |                    |
| hint            | Hint text to help the user with input |                    |

## Usage

<Code
	language="tsx"
	code={`<FileUpload
		title="Drag and drop files to upload"
		description="JPG, PNG, GIF or other image files"
		hint="Hint text to help the user with input"		
		sizes="lg"
		variant="input"
		accept="image/*"
		label="File"
		rounded="lg"
		maxSize={50}
		disabled={false}
		maxFiles={4}
/>`}
/>
