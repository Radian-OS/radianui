##### Installation

<Code language="bash" tabs={true} code={`radianos add file-upload`} />

##### Imports

<Code language="tsx" code={`import FileUpload from "@/components/ui/file-upload"`} />

##### Props

| Prop Name       | Default Values | Values                         |
| --------------- | -------------- | ------------------------------ |
| variant         | input          | input/container                |
| accept          | image          | image,document,audio,video,all |
| rounded         | lg             | xs,sm,md,lg,xl,2xl             |
| maxSize (in mb) | 5              |                                |
| label           | true           | true/false                     |
| disabled        | false          | true/false                     |
| multiple        | true           | true/false                     |
| maxFile         | 4              |                                |

##### Usage

<Code
	language="tsx"
	code={`<FileUpload
		variant="input"
		accept={["image","audio"]}
		label="File"
		rounded="lg"
		maxSize={50}
		multiple={true}
		disabled={false}
		maxFile={4}
/>`}
/>
