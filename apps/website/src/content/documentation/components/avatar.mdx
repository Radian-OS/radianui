| Prop Name | Default Value | Possible Values                                            |
| --------- | ------------- | ---------------------------------------------------------- |

| name      | -             | string                                                     |
| size      | "36"          | "16", "20", "24", "28", "32", "36", "40", "48", "64", "80" |
