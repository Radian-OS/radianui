##### Props

###### Accordion

| Prop Name   | Default Value | Possible Values        |
| ----------- | ------------- | ---------------------- |
| size        | `"sm"`        | `"sm", "lg"`           |
| variant     | "box"         | "box", "table", "open" |
| interaction | "single"      | "single", "multiple"   |
| disabled    | false         | boolean                |
