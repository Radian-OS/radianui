##### Props

| Prop Name | Default Values | Values        |
| --------- | -------------- | ------------- |
| Icon      | Plus           | Plus, Chevron |
| Animation | Yes            | Yes/No        |
| Size      | Default        | Values        |
| Source    | -              | -             |
| Style     | Default        | Boxes, XYZ    |

##### Syntax

| Prop Name     | Props                         | Description             |
| ------------- | ----------------------------- | ----------------------- |
| `<Accordion>` | Icon, Animation, Size, Styles | Main Container          |
| `<AccItem>`   | -                             | Container for each item |
| `<AccHead>`   | -                             | Headers                 |
| `<AccBody>`   | -                             | Body                    |
