## Props

| Prop Name | Default Values | Values         |
| --------- | -------------- | -------------- |
| size      | 24             | 20, 24, 28, 32 |
| variant   | outline        | outline,strong |
| rounded   | false          | true/false     |
| closable  | false          | true/false     |
