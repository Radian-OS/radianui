## Installation

<Code language="bash" tabs={true} code={`radianos add select`} />

## Imports

<Code language="tsx" code={`import { Select, SelectGroup, SelectItem } from "@/components/ui/select"`} />

## Props

| Prop Name     | Default Values | Values             |
| ------------- | -------------- | ------------------ |
| rounded       | lg             | xs,sm,md,lg,xl,2xl |
| size          | 36             | 28,32,36,40,44,48  |
| label         |                |                    |
| disabled      | false          | true/false         |
| placeholder   |                |                    |
| variants      | button         | input,button,tags  |
| searchable    | false          | true/false         |
| selectionMode | single         | single/multiple    |
| lead          |                |                    |
| hint          |                |                    |
| hasError      | false          | true/false         |
| startContent  | icon           |                    |
| endContent    | icon           |                    |
