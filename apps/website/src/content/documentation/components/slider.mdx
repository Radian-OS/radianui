## Installation

<Code language="bash" tabs={true} code={`radianos add slider`} />

## Imports

<Code language="tsx" code={`import Slider from "@/components/ui/slider"`} />

## Props

| Prop Name    | Default Values | Values              |
| ------------ | -------------- | ------------------- |
| label        |                |                     |
| disabled     | false          | true/false          |
| withInput    | false          | true/false          |
| showSteppers | false          | true/false          |
| showTooltip  | true           | true/false          |
| prefixIcon   | false          | true/false          |
| suffixIcon   | false          | true/false          |
| marks        |                |                     |
| orientation  | horizontal     | horizontal/vertical |

## Usage

<Code
	language="tsx"
	code={` 
<Slider
    label="Select volume label"
    disabled={false}
    withInput={false}
    showSteppers={false}
    showTooltip={true}
    prefixIcon={<VolumeX />}
    suffixIcon={<VolumeX />}
    marks={
        [
			 { value: 0, label: "0%" },
			 { value: 20, label: "20%" },
			 { value: 40, label: "40%" },
			 { value: 60, label: "60%" },
			 { value: 80, label: "80%" },
			 { value: 100, label: "100%" }
		   ]
			}
    orientation="horizontal"
/>`}
/>
