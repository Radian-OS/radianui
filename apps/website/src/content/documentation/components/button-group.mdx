##### Installation

<Code language="bash" code={`npx radianos add buttongroup`} />

##### Imports

<Code language="tsx" code={`import {Buttongroup,Button} from "@/components/ui/Buttongroup"`} />

##### Props

| Prop Name | Default Values | Values                                        |
| --------- | -------------- | --------------------------------------------- |
| variant   | strong         | strong, soft, outline, ghost, neutral-outline |
| size      | base           | 32, 36, 40, 44, 48, 56                        |
| rounded   | rounded        | square, rounded, full                         |
| isIcon    | false          | true/false                                    |

##### Usage

<Code
	language="tsx"
	code={`<Button variant="strong" size="36" rounded="rounded"/>

 </Button>
 `}
