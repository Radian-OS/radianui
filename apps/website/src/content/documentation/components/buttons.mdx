##### Installation

<Code language="bash" code={`npx radianos add button`} />

##### Imports

<Code language="tsx" code={`import {Button} from "@/components/ui/Button"`} />

##### Props

| Prop Name | Default Values | Values                                        |
| --------- | -------------- | --------------------------------------------- |
| variant   | strong         | strong, soft, outline, ghost, neutral-outline |
| size      | base           | 32, 36, 40, 44, 48, 56                        |
| rounded   | rounded        | square, rounded, full                         |
| isIcon    | false          | true/false                                    |

##### Usage

<Code
	language="tsx"
	code={`<Button variant="strong" size="base" rounded="rounded" isIcon={false}/>
   Button
 </Button>
 `}
