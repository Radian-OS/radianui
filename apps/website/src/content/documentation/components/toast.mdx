##### Installation

##### Imports

<Code language="tsx" code={`import Sonner from "@/components/ui/sonner"`} />

##### Props

| Prop Name     | Default Values | Values                                                                    |
| ------------- | -------------- | ------------------------------------------------------------------------- |
| position      | bottom-left    | top-left, top-center, top-right, bottom-left, bottom-center, bottom-right |
| variant       | default        | bg1, information, success, error, warning                                 |
| stackable     | boolean        | true/false                                                                |
| closable      | boolean        | true/false                                                                |
| visibleToasts | number         | 3, 4, 5                                                                   |

##### Usage

<Code
	language="tsx"
	code={`<Toaster position="top-left" visibleToasts={3} expand={true} />

closable:"true",
