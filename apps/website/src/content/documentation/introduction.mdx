Welcome to RadianOS documentation!

Radian is a system designed to help teams, indie hackers, developers and designers innovate much faster. It is a complete ecosystem of product interfaces mainly for web development.

Our aim is to help reduce the dependencies on your product and applications. Keep it lean and fast. Radian can be used both as a starting point for your project or the finish line. It allows the team to own their code and customize it to the fullest potential while keeping the project fairly simple.
